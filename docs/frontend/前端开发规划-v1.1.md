## 1. 项目现状快照

### 1.1 技术栈

| 层 | 现状 |

| 页面 | 原生 HTML5 + CSS3 + ES2017 多页面，页面间整页跳转 |

## 2. 页面与已实现功能

### 2.1 欢迎页 `welcome.html`

- 星空粒子背景：多层星点、流星、鼠标视差，由 `starfield.css/js` 实现。
- 页脚「动效」开关，状态写入 `chirpStarMotionV2`。
- CTA 按钮点击后产生波纹过渡并进入 `/index.html`。
- 已存在 `chirpToken` 时直接跳转 `/home.html`。
- 后端依赖：无。

### 2.2 登录 / 注册 `index.html`

- 双 Tab 切换登录与注册，注册态显示昵称、确认密码与密码强度。
- 密码使用 RSA-OAEP(SHA-256) 加密：先取 `/api/auth/public-key`，再提交密文。
- 「记住我」：勾选写 `localStorage`，否则写 `sessionStorage`，键为 `chirpToken`、`chirpUser`。
- 登录连续失败 5 次后本地锁定 30 秒。
- 登录/注册成功进入 `/home.html`。
- 短视口下环绕卫星卡隐藏，表单与页脚可滚动。
- 接口：`GET /api/auth/public-key`、`POST /api/auth/login`、`POST /api/auth/register`。

### 2.3 首页 `home.html`

- 左侧图标坞：首页、探索、通知、消息、收藏、个人主页，外加发布按钮与账号卡。
- 共享液态玻璃滑块：点击、鼠标拖动、触摸滑动均可切换；仅「首页 / 个人主页」使用 `data-view` 在页内切换，其余跳转独立页面。
- 顶部控制台：标题、搜索框、推荐 / 关注 Tab。
- 双信息卡：正在鸣响（话题趋势）与可能感兴趣的人，等宽等高、各自独立滚动。
- 信息流：加载中、加载失败重试、关注流空态、新帖高亮。
- 发布浮层：入口为左侧发布按钮；`Ctrl / Cmd + Enter` 快捷发布；前端上限 280 字符。
- 互动：点赞、收藏、关注建议用户、评论面板（懒加载、发评论、删除自己的评论）、删除自己的帖子；点赞与收藏为乐观更新，失败回滚。
- 转发按钮仅做本地计数，不调用后端。
- 通知角标与私信角标来自真实未读数，为 0 时隐藏。
- 登出：先调用 `POST /api/auth/logout`（`keepalive`），无论成败都清理本地并跳转登录页。
- 接口：见第 3 章。

### 2.4 个人主页（首页内嵌 + 独立页）

- 首页内嵌面板：保留左侧图标坞与滑块，只切换中间内容，URL 仍为 `/home.html`。
- 资料卡：昵称、handle、简介、加入日期、鸣响 / 关注 / 粉丝统计。
- 编辑资料：昵称 2-120、简介 ≤200、头像链接 ≤500；保存后同步首页账号卡与 `chirpUser` 缓存。
- 我的鸣响：分页加载、删除自己的帖子、空态。
- 每次进入内嵌个人主页都会重新拉取资料与帖子，避免发布后数据过期。
- 独立页 `profile.html` 仍保留，供直接访问；导航不再指向它。
- 接口：`GET /api/users/me`、`PUT /api/users/me`、`GET /api/users/{id}/posts`、`DELETE /api/posts/{id}`。

### 2.5 探索 `explore.html`

- 搜索框输入后进入搜索结果视图，分「帖子 / 用户」两个 Tab。
- 默认视图：正在鸣响（趋势）、活跃作者、最新鸣响。
- 活跃作者由最新帖子作者聚合，再逐个请求用户详情，排除自己，最多 6 人。
- 关注 / 取关按钮在同页多处同步状态。
- 接口：`GET /api/search`、`GET /api/hashtags/trending`、`GET /api/posts?scope=latest`、`GET /api/users/{id}`、`POST/DELETE /api/users/{id}/follow`。

### 2.6 话题 `topic.html`

- 读取 `?tag=`，标题显示 `#话题`。
- 通过 `GET /api/search?q=<tag>&type=post&limit=50` 拉取候选，再用 `#tag` 正则精确过滤。
- 显示命中条数与空态；无独立话题接口。
- 接口：`GET /api/search`。

### 2.7 通知 `notifications.html`

- 列表按时间倒序，分页 20 条，支持「加载更多」。
- 未读通知高亮，显示未读总数。
- 「全部标为已读」与点击单条标记已读。
- 空态与加载失败提示。
- 接口：`GET /api/notifications`、`POST /api/notifications/read`。

### 2.8 消息 `messages.html`

- 会话列表：对方资料、最后一条消息、未读数、总未读。
- 聊天视图：进入会话后拉取最近 30 条，支持「加载更早消息」，发送后追加气泡。
- 支持 `?with=<userId>` 直接打开与某人的会话。
- 进入会话自动标记该会话已读；发送支持 Enter，Shift+Enter 换行。
- 接口：`GET /api/messages/conversations`、`GET /api/messages`、`POST /api/messages`、`POST /api/messages/read`、`GET /api/users/{id}`。

### 2.9 收藏 `bookmarks.html`

- 收藏列表分页 20 条，显示收藏总数。
- 点击「已收藏」取消收藏，卡片移除并更新计数。
- 空态、加载失败提示。
- 接口：`GET /api/bookmarks`、`DELETE /api/posts/{id}/bookmark`。

### 2.10 忘记密码 `forgot-password.html`

- 邮箱预填（从登录页带入）、提交提示、60 秒重发冷却。
- 接口：`POST /api/auth/forgot-password`。

## 4. 鉴权与会话

| 项 | 现状 |
|---|---|
| Token 存储 | `localStorage.chirpToken` 或 `sessionStorage.chirpToken` |
| 用户缓存 | `chirpUser`（JSON：id / name / email / handle 等） |
| 记住我 | 勾选持久化到 `localStorage`，否则 `sessionStorage` |
| 请求头 | 需要登录的请求带 `Authorization: Bearer <token>` |
| 401 处理 | 部分页面清理本地并跳 `/index.html`；多数未携带 `?next=` |
| 登出 | 调用 `/api/auth/logout` + 本地清理；接口失败也照常退出 |
| 网关校验 | 网关查 Redis token，注入 `X-User-Id`；无效返回 401 JSON |

## 5. 视觉与交互体系

### 5.1 设计令牌与字体

- `dream-theme.css` 定义深空底色、紫/粉/青三色光、玻璃描边、圆角、间距、缓动与字体栈。
- 标题使用 `Noto Serif SC` 衬线，正文使用 `Noto Sans SC` / `DM Sans`。
- 渐变文字、回声标题、下划线光带用于欢迎页与首页主标题。

### 5.2 导航液态滑块

- `home.html` 导航内含共享 `#nav-liquid`，`nav-liquid.js` 计算目标项的位置与尺寸。
- 支持点击、拖拽、触摸；拖拽时缩短过渡时长。
- 选中项 `.active` 与 `aria-current` 同步；`data-view` 项派发 `chirp:view`，不跳转页面。
- 探索 / 通知 / 消息 / 收藏仍整页跳转，属于当前产品选择。

### 5.3 内嵌视图

- `#view-home` 与 `#view-profile` 通过 `.hidden` 切换，`aria-hidden` 同步。
- `document.title` 随视图更新，切换时回到顶部。
- 不改变 URL，不整页刷新；浏览器前进/后退不参与视图状态。

### 5.4 动效

- 入场：`motion.js` 使用 `IntersectionObserver` 与 `MutationObserver`，支持动态插入节点。
- 星空：CSS 多层星点 + DOM 粒子 + 视差 + 流星，非 canvas 重绘。
- 减少动效：`prefers-reduced-motion` 下压缩或关闭非必要动画，保留导航滑块反馈。

### 5.5 响应式

- 主要断点：1180 / 1080 / 980 / 880 / 760 / 720 / 600 / 420 px，另有短视口高度断点 720 / 760 px。
- 720 px 以下双信息卡改为单列；600 px 以下隐藏「可能感兴趣的人」。
- 600 px 以下左侧图标坞变为底部导航，发布按钮变为浮动按钮。

## 6. 安全与合规

- `server.mjs` 的 CSP：`default-src 'none'`、`script-src 'self'`、`style-src 'self' https://fonts.googleapis.com`、`font-src https://fonts.gstatic.com`、`img-src 'self' data:`、`connect-src 'self' http://localhost:8080`、`frame-ancestors 'none'`。
- 所有用户输入渲染前经过 `escapeHTML`，禁止 innerHTML 直插未转义数据。
- 不使用内联 `<script>`、内联事件属性、`eval` / `new Function`。
- 头像使用 `data-av` 变体 + 首字母，不依赖外域图片；`avatarUrl` 字段当前只做保存，不实际渲染。
- Token 不写入 URL、不写入日志；登出时服务端主动删除 Redis 记录。

## 7. 分页、时间与空态

| 场景 | 分页 | 说明 |
|---|---|---|
| 首页信息流 | 无 | 默认拉取 20 条，无「加载更多」 |
| 评论面板 | 固定 50 | 不支持评论分页 |
| 探索最新 | 30 | 无分页 |
| 话题 | 50 | 搜索候选上限 50 |
| 通知 | 20 | 支持加载更多 |
| 私信 | 30 | 支持加载更早 |
| 收藏 | 20 | 支持加载更多 |
| 用户帖子 | 20 | 个人主页暂未分页 |

- 首页与内嵌个人主页：7 天内显示相对时间，≥7 天显示 `YYYY-MM-DD`。
- 其他页面：30 天内显示相对时间，更早显示本地化日期（未完全统一）。
- 所有列表均有加载超时提示或空态；首页额外提供「重新加载」。

## 9. 已知限制与技术债

| # | 问题 | 影响 | 建议 |
|---|---|---|---|
| F1 | 首页发布上限 280，后端允许 500 | 长文被前端提前拦截 | 统一为 500，或后端改为 280 |
| F2 | 首页搜索只在当前已加载信息流中过滤 | 搜不到未加载的帖子 | 回车跳转 `explore.html?q=` 或调用 `/api/search` |
| F3 | 转发按钮仅本地计数 | 刷新即丢失，且无后端字段 | 明确隐藏或接入转发接口 |
| F4 | 推荐关注为 3 个固定 handle，再用搜索接口补全资料 | 不是真实推荐 | 后端提供推荐接口或改为运营配置说明 |
| F5 | 探索「活跃作者」由最新帖子推导 | 不是活跃度排序 | 后续接推荐/热度接口 |
| F6 | 话题页依赖搜索 + 正则过滤 | 超过 50 条会漏，且非精确话题索引 | 后端提供话题聚合接口 |
| F7 | `avatarUrl` 不参与渲染 | 用户设置头像后不显示 | 统一头像组件，支持 URL 回退首字母 |
| F8 | `API_BASE`、`escapeHTML`、`timeAgo`、头像工具在多个 JS 重复 | 维护成本高 | 抽取只读公共脚本（不引入构建） |
| F9 | 时间格式两套规则 | 页面间显示不一致 | 统一为 7 天规则 |
| F10 | 401 跳转不带 `?next=` | 登录后无法回到原页面 | 统一鉴权失效处理 |
| F11 | 通知角标不会因进入通知页自动清零 | 需手动点已读 | 进入页面后可选择性自动全标已读 |
| F12 | 无自动化测试与联调夹具 | 回归靠手工 | 增加契约冒烟脚本与关键路径手工清单 |
| F13 | 首页之外页面无左侧图标坞 | 页面切换体验不一致 | 已由产品确认仅个人主页内嵌，保持现状 |
